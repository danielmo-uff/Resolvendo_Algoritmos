# Resolvendo Algoritmos

Repositório para prática de algoritmos usando várias linguagens.

## Estrutura

- `python/` — soluções em Python
- `c/` — soluções em C
- `cpp/` — soluções em C++
- `rust/` — soluções em Rust
- `java/` — soluções em Java
- `javascript/` — soluções em JavaScript
- `typescript/` — soluções em TypeScript
- `sql/` — exercícios e scripts SQL
- `docs/` — anotações, explicações e revisões

## Como usar

Coloque cada arquivo dentro da pasta da linguagem correspondente.

Exemplos:

- `python/soma.py`
- `c/soma.c`
- `cpp/soma.cpp`
- `sql/consulta.sql`

Depois é só fazer:

    git add .
    git commit -m "mensagem"
    git push
